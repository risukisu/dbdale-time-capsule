## The Story

Somewhere around 2001, two Polish kids who'd been friends since kindergarten decided the internet needed another Dragon Ball fan site. One of them — "Eljot" — handled the HTML. The other — "Gusio" — wrote the content. They were maybe 12, armed with [Pajączek 2000 PRO](https://en.wikipedia.org/wiki/Paj%C4%85czek) (a Polish HTML editor that was *the* tool back then), a `poczta.fm` email address, and the absolute conviction that their site would be the best DB page on the Polish internet.

It had everything a proper fan site needed: character profiles, saga breakdowns, a gallery with hand-picked JPEGs and GIFs, wallpapers, a Flash intro, and — the crown jewel — a **homebrew Dragon Ball pen-and-paper RPG** with its own chapter system, races, and power levels. They spent months designing mechanics and playtesting it with friends before writing it up like a real tabletop rulebook.

Then life happened. The site disappeared. The files sat on an old hard drive for 25 years.

In 2026, one of the creators found the folder — still intact — and sent it over as a RAR archive. Broken image paths, mangled Polish characters, dead links. Fifteen minutes with [Claude Code](https://claude.ai/code) later, it was alive again.

The full story: **[How to Revive a 25-Year-Old Website](https://risu.pl/blog/how-to-revive-a-25-year-old-website/)**

## What's Inside

```
index.html          — Entry point (Flash intro, remember those?)
index2.htm          — Main hub with frames navigation
style.css           — Custom scrollbar colors, Verdana 12px, the works
postacie.htm        — Character profiles (Goku, Vegeta, Piccolo, Trunks...)
sagi.htm            — Saga guides
galeria.htm         — Image gallery (art, screenshots, wallpapers)
filmy.htm           — Movie guides
ssj.htm             — Super Saiyan transformation breakdown
kule.htm            — Dragon Ball lore
db rpg/             — The homebrew RPG system (6 chapters)
aktualizacja/       — A later revision of the site (never published)
pics/               — All the original images, GIFs, and fan art
multimedia/         — A single .rm file (RealMedia — peak 2001)
```

## Tech Stack (circa 2001)

- **Editor:** Pajączek 2000 PRO v4.8.0
- **Markup:** Raw HTML with `<table>` layouts and `<EMBED>` tags
- **Styling:** CSS with IE-era `SCROLLBAR-FACE-COLOR` properties
- **Animation:** Macromedia Flash (SWF)
- **Video:** RealMedia (.rm)
- **Charset:** Originally Windows-1250, now UTF-8
- **SEO strategy:** A `<META>` keywords tag with every Dragon Ball term imaginable, plus "mordobicie" (Polish slang for brawling)

## Recovery (2026)

Pulled from a 25-year-old hard drive, sent as a RAR file, and restored with Claude Code:
- Fixed image paths and broken links
- Re-encoded Polish characters from Windows-1250 to UTF-8

This is a time capsule. It's supposed to look like 2001.
